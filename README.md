# Wisely Studio 👔

A premium modern template for men's fashion, clothing, and accessories. This project includes a fully responsive frontend interface built with HTML5, CSS3, and JavaScript, along with a real-time shopping cart functionality using LocalStorage.

## 🚀 Features

- **Responsive Design**: Fully responsive layout that looks great on mobile, tablet, and desktop devices.
- **Real-Time Shopping Cart**: Interactive cart system that saves state across sessions using LocalStorage. You can add, remove, and adjust product quantities seamlessly.
- **Modern UI Components**: Clean and luxury design aesthetic tailored for fashion brands.
- **SEO Optimized**: Includes proper meta tags and Open Graph data for better search engine visibility and social media sharing.

## 🛠️ Built With

- HTML5 & CSS3
- JavaScript (jQuery, Owl Carousel, MixItUp, Nice Select)
- Bootstrap Framework
- LocalStorage (For Cart Persistence)

## 💻 Getting Started

To run the project locally, you don't need any complex server setup.

1. Clone this repository:
   ```bash
   git clone https://github.com/Shiryx0242/Wisely-Studio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Wisely-Studio
   ```
3. Open `index.html` in your favorite web browser to view the site.
